# Практика SQL для аналитики данных (PostgreSQL)

В репозитории собраны практические SQL-запросы, структурированные по 4 ключевым блокам: от базовой фильтрации до подзапросов, CTE и оконных функций. 

Все запросы написаны на базе PostgreSQL и ориентированы на решение реальных задач аналитики (расчет ключевых метрик, агрегация продаж, работа с клиентами и связка справочников).

---

## 📁 Структура проекта

* `schema/schema.sql` — скрипт инициализации тестовой базы данных (структура таблиц и тестовые записи).
* `sql/01_basics_filtering.sql` — базовая выборка, фильтрация и сортировка.
* `sql/02_aggregation.sql` — агрегатные функции, группировка данных и фильтрация групп.
* `sql/03_joins.sql` — объединение таблиц различных типов (INNER, LEFT JOIN).
* `sql/04_subqueries_and_cte.sql` — вложенные запросы, обобщенные табличные выражения (CTE) и оконные функции.

---

## 🛠 Ключевые используемые конструкции

### Блок 1. Выборка и фильтрация (`01_basics_filtering.sql`)
* Операторы: `SELECT`, `WHERE`, `ORDER BY`, `LIMIT`.
* Условия и шаблоны: `BETWEEN`, `IN`, `LIKE`, `ILIKE`, обработка `NULL` (`IS NULL`, `COALESCE`).

### Блок 2. Агрегация и группировка (`02_aggregation.sql`)
* Агрегатные функции: `SUM()`, `AVG()`, `COUNT()`, `MIN()`, `MAX()`.
* Группировка и фильтрация групп: `GROUP BY`, `HAVING`.
* Расчет бизнес-метрик: средний чек, объемы продаж, количество уникальных пользователей (`COUNT(DISTINCT)`).

### Блок 3. Объединение таблиц (`03_joins.sql`)
* Связывание данных: `INNER JOIN`, `LEFT JOIN`, `RIGHT JOIN`.
* Фильтрация и подтягивание справочников без потери основных категорий.

### Блок 4. Подзапросы, CTE и оконные функции (`04_subqueries_and_cte.sql`)
* Подзапросы в блоках `WHERE` и `FROM`.
* Конструкция `WITH` (CTE) для читаемости сложных многошаговых запросов.
* Оконные функции: `ROW_NUMBER()`, `DENSE_RANK()`, `SUM() OVER()`, `LAG()` / `LEAD()` для расчета динамики и ранжирования.

---

## 🚀 Как запустить локально

1. Развернуть базу данных PostgreSQL.
2. Выполнить скрипт `schema/schema.sql` для создания таблиц и вставки тестовых данных.
3. Запускать скрипты из папки `sql/` в любом SQL-клиенте (DBeaver, pgAdmin, VS Code).
